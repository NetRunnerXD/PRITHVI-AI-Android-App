# Clone and Android Studio

This is an **Expo** app. The live API is always:

`https://rituchakra-api.onrender.com`

Do not point it at a local Python server.

## Folder name

Avoid spaces in the path (`PRITHVI-AI App` breaks some Gradle/NDK tools). Prefer `prithvi-ai-app`.

## Machine requirements

- Node **20+** (see `.nvmrc`)
- JDK **17** (Temurin or Android Studio JBR). Set `JAVA_HOME`. **Do not** put a user-specific `org.gradle.java.home` in `gradle.properties`.
- Android Studio: SDK Platform **34+** (36 after Expo SDK 57 prebuild), Android SDK Build-Tools, NDK if you generate a native project.

## First-time clone

```bash
npm install
copy .env.example .env   # Windows; already defaults to Render
npx expo start -c
```

Expo Go can load JS. Voice GPS needs a native build:

```bash
npx expo prebuild --clean
npx expo run:android
```

## Android Studio (SDK 57 native project)

`android/` is generated by `npx expo prebuild` (Gradle 9.3, New Architecture on). After a clone, regenerate if `android/` is missing or still Expo 51:

```bash
npm install
npx expo prebuild --platform android --clean
```

Then:

1. **File → Open** → select the **`android`** folder (not the JS root).
2. Wait for Gradle sync. First sync downloads Gradle 9.3.1.
3. Gradle JDK: **Settings → Build → Gradle → Gradle JDK → 17** (or 21). Do not use a leftover `C:\Users\souna\.jdks\...` path.
4. Let Studio write `android/local.properties` (`sdk.dir=...`).
5. Start Metro in a second terminal: `npx expo start` from the app root.
6. Run ▶ **app**.

Package id: `com.prithvi.ai`. App name: **PRITHVI-AI**. API: `https://rituchakra-api.onrender.com`.

If you see “invalid Java home” pointing at `C:\Users\souna\...`, that path was removed from `gradle.properties`. Use your own JDK.

## Expo SDK upgrade (57)

```bash
npx expo install expo@^57
npx expo install --fix
npx expo-doctor
rmdir /s /q android
npx expo prebuild --clean
```

SDK 51 native folders will not compile cleanly on a fresh Studio install of SDK 36 — regenerate them.
